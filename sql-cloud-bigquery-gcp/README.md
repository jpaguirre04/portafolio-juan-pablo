# ☁️ Proyectos de Análisis de Datos en la Nube con Google Cloud Platform (BigQuery)

En este módulo se presentan consultas analíticas avanzadas desarrolladas en **Google BigQuery**, 
orientadas al procesamiento eficiente de grandes volúmenes de datos (*Big Data*), análisis exploratorio 
y optimización de consultas SQL en la nube.

## 🛠️ Tecnologías Utilizadas
* **Google Cloud Platform (GCP)**
* **Google BigQuery**
* **Standard SQL (GCP)**

## 📂 Contenido de los Scripts
* Consultas para análisis exploratorio y agregación de Big Data.
* Optimización de datos, particionamiento y estructuración de tablas.
