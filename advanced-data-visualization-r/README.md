
# 🎨 Visualización Avanzada de Datos & Storytelling en R

Este módulo reúne scripts y funciones desarrolladas en **R** para la construcción de gráficos avanzados, reportes visuales y exploración gráfica de datos (*Exploratory Data Analysis - EDA*).

---

## 💡 Objetivos del Módulo
El propósito de este repositorio es demostrar el uso de técnicas modernas de visualización para transformar conjuntos de datos complejos en representaciones gráficas claras, rigurosas y estéticamente profesionales para la toma de decisiones.

---

## 📊 Contenido y Técnicas Aplicadas

* 📈 **Visualización Multivariada:** Representación gráfica de distribuciones complejas, correlaciones y tendencias.
* 🎨 **Personalización y Temas Avanzados:** Uso avanzado de la gramática de gráficos (`ggplot2`), paletas de colores optimizadas y composición gráfica.
* 🛠️ **Pipelining & Data Wrangling:** Transformación y preparación previa de datos con el ecosistema `tidyverse`.

---

## 🛠️ Tecnologías y Librerías
* **Lenguaje:** R (`.R` scripts).
* **Librerías Clave:** `ggplot2`, `tidyverse`, `scales`, `gridExtra` / `patchwork`.
