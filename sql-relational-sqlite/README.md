# 🗄️ Proyectos de Análisis de Datos y Consultas Relacionales (SQLite & Python)

En este módulo se presentan proyectos de análisis de datos basados en bases de datos relacionales SQLite, 
procesados e integrados mediante Python.

## 🛠️ Tecnologías Utilizadas
* **SQL / SQLite**
* **Python**
* **Spyder IDE**

## 📂 Contenido de los Scripts
* Modelamiento de bases de datos relacionales y diseño de esquemas.
* Consultas para análisis exploratorio, agregaciones, filtrado avanzado y *joins*.
* Integración de datos procesados directamente en scripts `.py`.
